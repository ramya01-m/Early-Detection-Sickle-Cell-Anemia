# Dataset

This project uses a blood smear image dataset for the classification of:

- Normal
- Sickle

The images are organized into two folders based on their class.

## Dataset Structure

```text
sickle-cell-disease-dataset/
│
├── Normal/
│   └── Normal blood smear images
│
└── Sickle/
    └── Sickle cell images
Usage

The dataset is used for training and evaluating the deep learning model for
Sickle Cell Anemia image classification.
